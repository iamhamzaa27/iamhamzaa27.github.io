## About

This repository powers [iamhamzaa27.github.io](https://iamhamzaa27.github.io/), the academic portfolio of Muhammad Hamza. It presents research in quantum information science, quantum machine learning, reinforcement learning, intelligent sensing, and next-generation communication systems.

## Research areas

- Quantum circuit optimization and hybrid quantum–classical learning
- Reinforcement learning and agentic AI
- Quantum and classical sensing
- AI-enabled wireless and 6G communication systems
- Computer vision and deep learning

## Local development

The website is built with HTML, CSS, JavaScript, and JSON data files. Clone the repository and serve its root with any static web server:

```bash
git clone https://github.com/iamhamzaa27/iamhamzaa27.github.io.git
cd iamhamzaa27.github.io
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Updating content

- Edit `index.html` for the page structure and static profile/contact information.
- Edit files under `data/` for publications, projects, experience, skills, and highlights.
- Edit `assets/css/styles.css` for presentation and `assets/js/script.js` for site behavior.
- Replace `assets/images/profile/muhammad-hamza.jpg` to update the profile portrait.
